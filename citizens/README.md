# صفحة تسجيل المواطنين (`/citizens/`)

صفحة ثابتة (RTL) يملؤها عون الإدارة لتسجيل مواطن في Google Sheet، مع مؤشر أهمية بأربع درجات.
الصفوف في الورقة تُلوَّن وتُرتَّب تلقائيًا: الأهم أولًا، ثم الأقدم تسجيلًا ضمن الدرجة نفسها.

## الإعداد
1. أنشئ ملف Google Sheet خاصًا وانسخ معرّفه (الجزء بين `/d/` و`/edit`).
2. افتح https://script.google.com وأنشئ مشروعًا والصق `apps-script/Code.gs`.
3. من Project Settings → Script properties أضف:
   - `SHEET_ID` = معرّف الملف
   - `ACCESS_CODE` = رمز سري لأعوان الإدارة
4. Deploy → New deployment → Web app: Execute as **Me**، Who has access **Anyone**. انسخ الرابط المنتهي بـ `/exec`.
5. ضع الرابط في `citizens/config.js` ثم انشر الموقع، فتظهر الصفحة على `/citizens/`.

## ملاحظات
- يُنشأ تبويب «المواطنون» تلقائيًا عند أول تسجيل.
- رمز الدخول يُتحقَّق منه في Apps Script وليس في المتصفح. أبقِ الملف خاصًا.
- بيانات المواطنين شخصية: لا تشارك الملف إلا مع المخوّلين.
